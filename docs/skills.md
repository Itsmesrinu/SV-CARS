# skills.md — Sri Venkateshwara Cars

## Goal

Merge the Stitch-generated pages into one consistent rental car website.

## Must keep

- Same shared header from the home project
- Same shared footer from the home project
- Same premium blue-based design language
- Same booking-first user flow
- Same responsive behavior for mobile and desktop

## Pages

- Home
- All Cars Fleet
- Car Details with Premium Gallery
- Booking / WhatsApp Confirmation
- Admin Dashboard

## Booking rules

- Booking should open WhatsApp with a prefilled message.
- The message must include:
  - car name
  - car type
  - booking days
  - total amount
  - pickup/location details
  - extra km rule if applicable
  - driver charge if applicable

## Pricing rules

- Use Indian Rupees only.
- Show per-day rate clearly.
- Show dynamic totals based on booking days.
- Show self-drive km limit and extra km charge.
- Show with-driver pricing separately if selected.

## Admin rules

- Admin can add/edit car details and photos.
- Admin can change availability.
- Admin only controls are not visible to customers.

## Navigation rules

- Home stays home.
- All Cars opens the fleet page.
- Reviews scrolls to the reviews section.
- Office Location scrolls to the office section.

## Safety rule

- Do not guess missing data.
- Do not change layout or colors unless asked.
- Keep imported pages inside the shared home layout.
